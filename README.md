# mayobimu Personal Website

技術や暮らしについての発信と活動をまとめる、mayobimuの個人サイトです。

## 開発環境

- Next.js
- TypeScript
- Tailwind CSS
- pnpm

## 起動方法

依存パッケージをインストールします。

```bash
pnpm install
```

開発サーバーを起動します。

```bash
pnpm dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## 確認

```bash
pnpm lint
pnpm build
```
